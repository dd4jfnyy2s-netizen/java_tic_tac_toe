# Java Tic-Tac-Toe

## 概要
Javaで作成した、2人対戦型のマルバツゲームです。

コンソール上で行番号と列番号を入力し、○と×を交互に配置して対戦します。

## 使用技術
- Java
- Scanner
- 2次元配列

## 主な機能
- 3×3のゲーム盤面表示
- ○と×の交互配置
- 入力範囲のチェック
- 使用済みマスへの重複配置防止
- 横・縦・斜めの勝敗判定
- 引き分け判定
- 勝利・引き分け時のゲーム終了

## 実行方法

プロジェクトのルートディレクトリで以下を実行してください。

```bash
javac lesson01/Main.java
java lesson01.Main
```
